# R1 — the name the tree carries into its first release

The rename procedure lives in `plan/rename.md`. This note records the part the procedure could not
supply: which name, why, and which road each candidate closed.

## What was measured

- **Registers.** TMview (TMDN), exact-string criterion, offices EUIPO + USPTO + WIPO, filtered to
  Nice 9 (software), 20 (furniture) and 42 (design services). A hit is reported with office, number,
  status, classes and owner.
- **Domains.** RDAP only: `.com` (Verisign), `.org` (PIR), `.dev`/`.app` (Google, through
  `rdap.org`). `.ru` **only** through `whois.tcinet.ru:43`, because the RDAP bootstrap lies for `.ru`:
  it reported `versta.ru`, `k3n.ru` and `lado.ru` as free while all three are registered, two of them
  since 2005 and 2022. `.eu`, `.tools`, `.works`, `.design` and `.build` answer no RDAP at all — they
  are confirmed with a registrar, and are marked "unconfirmed" here.
- **Stores.** iTunes search API, counting applications whose title starts with the string.
- **Ecosystem.** `crates.io` API, the npm registry, PyPI JSON, and `api.github.com/orgs/<name>`.
- **Rate limits.** TMview throttles after roughly forty queries and then times out at 60–90 s; queries
  are spaced two to three seconds apart, and a refusal is reported rather than guessed.

## Decisions

- **The product is `Z3L`** — Zero · 3 Laws (`Local`, `Literal`, `Lasting`); ADR 0135,
  `docs/philosophy.md`. Two further readings of the same string are recorded there.
- **The identity is four constants, not prose**: `theme::PRODUCT_NAME`, `APP_ID`, `project::FORMAT`
  and `project::EXTENSION`, so the next rename is one line per surface and a test catches a copy.
- **`APP_ID` is the short `z3l`**, so the settings path reads `~/.config/z3l`. A reverse-DNS
  id (`io.github.<owner>.z3l`) is the convention for `.desktop`, Wayland and Flatpak; it is a one-line
  change when a package ships.
- **Envelope `"furniture.scene"`**, because the format string names a contract and not a brand, and
  **extension `.z3l`**, because a file association is what a person sees.
- **Bare crate names** (`model`, `engine`, `render`). All are taken on crates.io, which matters only
  if we publish; a later publish can alias with `package = "…"` without touching a `use`.
- **Package `app`, binary `z3l`**, so `cargo run -p app` opens the editor and `target/debug/z3l` is
  the program.

Every three-symbol string has its `.com` taken, so `.com` is not a discriminator at this length; the
choice was made on the register and on whether the string is sayable.

## Left open

- `Takt` is the strongest unchecked candidate (one syllable, a word in both languages, "measure" and
  "tact" at once) and stays in the piggy bank.
- `.eu`, `.tools` and `.works` availability for `Z3L` is unconfirmed — no RDAP endpoint exists.
- The trademark check is a public-register search, not legal advice; it is re-run before the first
  public release, which is the point at which the name becomes expensive.
