# J26 — What was measured

## What was measured

- **The panel said one still line.** `app/src/chat.rs` drew `AssistantWorking` with the call count
  and nothing else: no clock, no step. The turn already knew more than it showed — `Turn::calls`
  and the checklist — but not what it had last done.
- **The OpenAI wire answered whole.** `crates/mcp/src/openai.rs` posted one completion with
  `stream` unset and read `read_json`, so nothing could appear before the whole answer did. The
  part-shaped reply already existed for the agent process (`Reply::part`, `Reply.more`, ADR 0230):
  the panel and `Turn` were ready, the HTTP backend was not.
- **A part was a new line.** `Conversation::push_answer` appended every reply as its own line and
  its own wire message, so a text piece per token would have been a label per token in the panel and
  a message per token in the history the model reads back.

## What was decided

- **A piece carries the answer so far, not the delta.** `Reply::saying_so_far` sets `text` to the
  whole of what was said, and `Conversation` grows one line in place (`open: Option<usize>`); the
  wire's history takes the answer once, when it is whole. A line index and not a flag, because a
  tool line may fall between two pieces.
- **The content type decides how the answer is read, not the flag that was sent.** A gateway that
  ignores `stream: true` answers `application/json` and the old reader takes it, so the feature
  cannot break an endpoint that does not stream.
- **One piece in flight.** The worker sends on a `sync_channel(1)` and blocks until the frame takes
  it, so a fast provider cannot queue an answer the panel will draw a second behind. The block ends
  when the turn drops its receiver, which is what Stop does.
- **The step is the last thing the turn did**, named by `Turn::current`: the last command of the
  batch it dispatched (`node.rename`) or the tool it read with (`command_list`). The checklist is
  drawn beside it and is the model's own words; no invented per-item status.
- **The panel asks for its frames while a turn runs**, as the render place does for its counter
  (ADR 0211). This pays the first half of the `[assistant]` line in `plan/debt.md`, which is tagged
  X122: that entry's frame clause is now delivered and its Send/Stop clause is not.

## Ruled out

- A per-sentence threshold in the worker: the bounded channel already coalesces, and a threshold
  would make a short answer arrive in one piece.
- Appending each delta (`Reply::part` with text): one label and one wire message per token.
- A new field on `Reply` for "this text replaces": `more` already means "the answer is not whole",
  and the two halves of a piece (`text` replaces, `lines` append) are documented on the field.
