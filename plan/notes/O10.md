# O10 — A hole is a crossing, and it is clipped against the panel the person made

## What was measured

- Nothing in the program derived a hole. `crates/model/src/panel/machining.rs` had exactly one
  authored kind, `Cutout`; `crates/catalog` had no part document and `crates/model/src/node.rs` had no
  instance node, so no scene could carry a drilling object. ADR 0150 was the target state only.
- The material a crossing must respect already existed: `PanelGeometry::core_region` is the panel's
  exact board in the nominal frame, `CutoutShape::region` an exact cutout, and `geom::Region` already
  solves exact containment. What was missing was a **line through a region**: `geom` could answer
  `contains` and nothing could clip an axis.
- The body a panel is drawn from is `param`'s, not the document's: `PanelPlan` folds booleans for the
  kernel. Drilling the drawn body would have cost one boolean per hole — a door's hinge and plate is
  about eight — before any scene can name a drilling object.
- `mesh::EvaluationCache` already compares derivation inputs rather than a revision, and
  `built_at(id)` is the observable "an untouched node is not recomputed" (X56). It had one key per
  panel; the holes have a different key from the mesh.

## Decisions

- **The derivation lives in `model` and is pure geometry.** `derive_holes(panel, geometry, placement,
  drillings)` answers `DerivedHoles { holes, diagnostics }`; no kernel, no kernel body, no catalogue.
  It is the "crossing computation" ADR 0150 warns is quiet when it is wrong, so it is a pure function
  with exact tests rather than a step inside an evaluation.
- **The drilling object is an input value, not a document field.** `Drilling` holds the resolved world
  point, unit direction, diameter and depth; the instance that resolves it out of a part document
  lands with task O13. This is what let the acceptance test — a known hinge on a known door — be
  written before the instance node exists.
- **A hole is panel-local micrometres.** Entry point `[Length; 3]`, unit direction in the panel frame,
  diameter, depth and a `through` mark. Rounding once, at the boundary, is what makes "exact
  coordinates" assertable; the value is never serialized.
- **The material is the core minus its through cutouts, not the nominal rectangle.** A bore near a
  rounded corner or beside a notch then follows the body (`a_bore_near_a_rounded_corner_...`). The
  clip is one parameter interval per dimension: `Region::line_intervals` for the plane and the slab
  across the thickness, intersected, then clipped to the drill's own reach.
- **Two diagnostics, both provable.** `Grazing` is a crossing of no positive length; `TooWide` is a
  bore whose projected circle leaves the boundary it enters through. A drilling object that never
  meets the body is not a diagnostic: every panel is offered every object, and a hinge's screws reach
  the carcass, not the door.
- **The holes are cached under a second key in the same entry.** `PanelEval` carries the panel, its
  geometry, its world placement, the drilling objects and the band profile closure; `HoleInputs`
  compares the panel's features, the placement and the objects without copying, so a frame allocates
  nothing. A moved hinge re-derives holes and keeps the body's `Arc` and `built_at`; `holes_built_at`
  reports the revision that derived them.
- **The drawn body is not drilled.** The Shape asks for the crossing and the cache, not for a bore on
  screen, and a boolean per hole is a cost that needs a measured need. The gap is in `plan/debt.md`.

## Ruled out

- **Drilling the mesh in `param`.** One kernel boolean per hole, and a hinge move would rebuild the
  body for a change nobody can see yet. `param` is untouched, and the note names why.
- **A separate hole cache in `engine`.** It would need its own `Stamp` and would answer holes per
  panel while the mesh cache already holds one entry per node with the panel's own inputs beside it.
- **Sampling the region to clip the axis.** The rings are exact and `Region::contains` is even-odd over
  lines and arcs; a sampled clip would put a hole within a chord of the right place and call it exact.
- **A diagnostic for a drilling object that misses.** It would fire for every screw on every panel of
  a carcass and say nothing a person can act on.
- **Storing the hole in the panel.** ADR 0150 forbids it: the moment a hinge model changes, a stored
  hole disagrees with the hardware that caused it.
