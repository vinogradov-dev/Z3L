## The cheap path

One sentence in the `spec.rs` module doc: a group of only planned tools is skipped, so moving the
grid cell out of `view.display` also removes its caption — the consequence that took the ADR 0066
and `toolbars.rs` reads, and the one fact that decided the Done clause.

## For the strategy

A UI entry whose Done names a caption should be written against the drawing loop, not the table: the
two differ exactly where a planned group disappears, which is the only interesting part of this
task. A hint that names a table should name its test module too, since the tests are where the shape
of an id lives. Stamp the clock at every phase change, not at every read — fourteen `~` lines cost
the review the one thing the column exists for.
