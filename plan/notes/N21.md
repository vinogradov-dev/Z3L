# N21 — snapping is a setting, and the coordinate planes stand in for walls

## What was measured

- `move_query.rs` held both snap constants: `SNAP_RADIUS_MM = 5.0` and `GRID_MM = 1.0`. The floor was
  the only coordinate plane with a candidate (`if axis == MoveAxis::Z { capture(0.0) }`), and no
  setting reached either number.
- The candidate walk is one closure over `movers × obstacles`; the two families of obstacle are
  already distinguishable by kind, because a product's envelope is `SurfaceKind::Shell` and a panel or
  a body is not. The switch could therefore be one `continue`, not a new list.
- `Project::move_rule(&[Id])` was read once per drag and `MoveRule::limit(axis, proposed)` answered
  every pointer position from it, so the settings had exactly one natural entry point.
- `TranslateGizmo::update` already took seven arguments and carried `#[allow(too_many_arguments)]`;
  `clippy`'s threshold is seven, so an eighth value was not an option and the snap settings entered
  `gizmo_math::Target` instead, which is the per-frame snapshot a drag already receives.
- The exact-distance fields do **not** see a snap: `measure_move` asks `Project::probe`, and a
  coordinate plane has no surface behind it. A drag that jumped to Y=0 would keep a field that said
  "no neighbour" — the Done clause about the field was therefore a real gap, not a formality.
- `app/src/settings_store.rs` round-trips `Settings` through a file and its `custom()` fixture is the
  one place a new section is proved to survive the atomic write.

## Decisions

- `model::SnapSettings { planes, frames, tolerance: Length }` owns the meaning and the default
  (`DEFAULT_TOLERANCE_MM = 5`); `ui::settings::SnapSettings` owns the file, the window and the
  endpoint range (1..=50 mm), and `rule()` converts millimetres into the document's unit once. A test
  ties the two defaults together, so the number exists in one place and is asserted in the other.
- Like the gizmo size and unlike the document, the value travels to `Target::snaps` per frame, but the
  drag reads it **once** at the start: a change mid-drag would otherwise bend the preview away from
  the placement the release commits.
- The planes are candidates on all three axes, and the floor is simply the Z=0 plane. Their switch is
  shared because the owner named the floor as one of them; a separate floor switch would offer a state
  where a piece jumps to an invisible plane but not to the visible floor.
- The frames switch removes the capture, never the stop. Contact is the document's rule (ADR 0102)
  and a taste that let one shell through another would be a defect.
- `MoveLimit` gained `capture: Option<Capture>` with `SnapEnd`, `at_mm` and `SnapSurface::{Plane,
  Frame, Face}`. It is dropped when a contact cuts the drag: the face then landed on the contact and
  the capture would name a surface the piece never reached.
- The shell overrides the probe's wall on the captured side with `capture.at_mm` before
  `Distances::sync`, and paints a helper-ink line across the face in the captured surface. One value
  feeds the line, the field and the release, which is what the Done asked for.
- A typed distance pins the face and reports no capture: the maker's number outranks a snap, exactly as
  ADR 0103 says the pointer loses to the field.

## Ruled out

- The tolerance as a per-drag modifier (Alt-like): the owner asked for the number to be a setting, and
  a modifier nobody can discover is not a setting.
- Snapping the *contact* off with the frames switch: see above — the preview would let two cabinets
  overlap.
- Storing the settings in the document: they are workspace state (ADR 0068), and the scene must not
  change behaviour because another machine wrote it.
- Deriving the captured side in the shell by comparing coordinates: the rule already knows which end
  landed, and a comparison would be a second measurement that can disagree.
- Adding a headless drag test: `TranslateGizmo::update` needs a live pointer, the same reason N5 left
  it untested; the rule, the release path and the field override are each tested on their own.
