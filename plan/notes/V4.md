# V4 — a body is drawn as a profile and swept on Z

## What was measured

- `crates/model/src/primitive.rs` stored three sides for a box and a radius, a height and a side
  count for a cylinder, so the only figure a body could be was the one those numbers describe.
  `Primitive::cuboid`/`cylinder`/`from_kind` were the whole creation vocabulary.
- The sketch already knew four rectangle methods and four circle methods (`DrawTool`), and
  `DrawDraft` committed every one of them as one `object.path.create`. The box tool knew two points
  and one rule (ADR 0101).
- `object.path.extrude` and `object.extrude.height.set` already exist, `param::build_constructive_mesh`
  already builds one extrusion of a ring analytically, and `ContourTarget::Object` already reshapes a
  constructive body's path in the viewport. A body needed no new geometry code.
- `Session::edit_scope`/`dispatch_in`/`cancel_edit` (ADR 0092) already make two commands one undo
  entry and roll a cancelled edit back, which is what a profile that becomes a body needs.
- A constructive body's card had no height field: `summary.height` was only a measure, and the pull
  arrow is armed only right after `object.path.extrude`. So a drawn box would have lost the height
  edit the cuboid card had.

## Decisions

- **The box and cylinder cells carry the sketch's methods.** `ToolKind::Body(DrawTool)` starts the
  same draft as `ToolKind::Draw`, so the plates, the snaps and the previews come for free; only what
  the commit becomes differs (`DrawIntent::Body`). A body cell names the method it draws so the
  tooltip does not read «From corner» twice.
- **The profile is a node for the length of the pull.** The commit stores `object.path.create` in an
  open edit scope, then the shell arms the existing height pull on that path; the ✓ dispatches
  `object.path.extrude` in the same scope, the ✕ or Escape calls `cancel_edit`. This reuses the
  shaded preview (`previewed_body` grew a path arm), the lettered `H` card and the arrow, and keeps
  one undo entry. The alternative — holding the ring in view state and committing
  `object.extrude.create` at the ✓ — needed a second wireframe paint for an arbitrary contour and a
  second pull target, and left nothing to select while the height is chosen.
- **The body is a `Geometry::Constructive`.** A profile and an extrusion is exactly what that payload
  is, so the mesh, the collapse, the contour edit and the card are the ones that already existed; the
  two retired shapes leave the schema instead of gaining a profile field.
- **The card gains the extrusion height.** `object.extrude.height.set` through the shared field and
  the edit scope, so a drawn box keeps width, depth and height as three fields. A rectangle profile of
  a body reads its second side as a depth, because the height below it is the sweep.
- **The frame keeps its own gesture.** A product reserves a box that is not a solid, so `BoxDraft`,
  the prism paint and the eight-corner grips stay for the *Frame by drawing* method; `BoxOwner` and
  its cuboid arm are gone.

## Ruled out

- **Keeping `Cuboid`/`Cylinder` and adding a profile beside them.** Two ways to store one shape, two
  meshers and a card that must decide which one it edits: the trap ADR 0101 removed for the box.
- **Committing `object.extrude.create` at the ✓ from a held ring.** Escape would cost nothing, but the
  preview needs a prism painter for any contour and the pull needs a target that holds no node.
- **A `segments` field for a cylinder.** A circle profile is sampled at the chord tolerance by
  `crates/param` (ADR 0062), so a facet count would be a second tessellation rule in the document.
- **Keeping the cuboid's ten grips on a drawn box.** The body's handles are the contour's corner
  grips; re-deriving the box editor for a profile would give one shape two grip sets.

## Looked at

- `app/src/frame_tests.rs` drives the whole gesture headlessly for every method: the box test asserts
  eight corners, six faces and the profile's area times the height, the cylinder test asserts the
  circle's area times the height within the sampling error of the rim, and one undo takes the profile
  and the body together. Escape during the pull leaves no revision and no history entry.
