# P24 — What was measured

## What was measured

- `state-contract/src/status.rs:51` printed `` -> Nothing is scheduled: `## Now` is empty, the
  backlog keeps the work `` whenever `STATE: task=-`, whatever the backlog held. Measured in
  `z3l-wt/render` at `0d77dce`: `## Now` held `[~] Y1`, so the sentence was false and the reader
  was sent past the work in hand to `## Next`.
- The section is the whole file's; the sentence spoke for one stream's slice of it. The gate keeps
  `## Now` legal while another checkout works a task there (`validate.rs` ›
  `the_state_line_names_the_plans_own_task_and_not_another_streams`), and only the `app` stream's
  task is what `STATE:` schedules.

## Decisions

- The sentence names the primary stream: `` no `app` task is in `## Now` ``. It is true in both
  layouts — an empty `## Now`, and another checkout's `[~]` task in it — and it is built from
  `PRIMARY`, the constant that already defines the plan's own key (`Streams::parse` refuses to
  declare `app`, so the key cannot drift from the sentence).
- `NOTHING_SCHEDULED` is still the first words of the line, so the block and the gate's `## Next`
  prefix stay one string; the constant's doc now says so.
- `state-contract/README.md` carried the same false claim ("`## Now` holds none"); it now says
  "none of the plan's own tasks", with a declared stream excepted.

## Ruled out

- **`Nothing is scheduled: the plan's own order is empty`.** True, and it is the wording the
  `## Next` paragraph uses, but it repeats what `task=-` already says and names nothing a reader
  can check. The stream is the part `task=-` does not carry.
- **Saying nothing when a stream works.** The block would then show an `idle` plan with a `[~]`
  row and no sentence tying them together, and the empty case would lose its one line.
- **Editing the historical quote in `plan/notes/P13.md`.** A note is what a session measured; the
  sentence it quotes is the one that shipped then.
