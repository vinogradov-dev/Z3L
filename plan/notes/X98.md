# X98 — A body's profile is the ring a contour boolean reads.

A body's profile is the ring a contour boolean reads.

## What was measured

The extrude cell keeps the node and swaps its payload: `Project::extrude_object_path`
(`crates/model/src/project/object_cmds.rs`) turns a `Geometry::Path` into
`Geometry::Constructive`, whose stored path is the very chain that was drawn. A contour
boolean then read its operands through `Project::object_path`, which answers
`NotAPathObject` for that payload, so `/home/alx/scene.z3l` — two extruded bodies and a cone —
refused both bodies as operands and the maker got 'node 2 is not a drawn contour'.

The rule the operation needs was written three times: `ring_in_base` and `ring_ready` in
`crates/engine/src/contour_cmds.rs` and `is_ring` in `crates/ui/src/editor/boolean.rs`, each
asking for a path payload and then `is_closed` plus `to_contour`. A body already answered the
second half: `Constructive::contour` is `path.to_contour`, and the body's placement is the flat
frame the ring was drawn in.

## Decisions

- The profile is a payload accessor, `Geometry::profile` (`crates/model/src/object.rs`): a
  path's chain or the path a body grew from, and nothing for a contour set (several rings), a
  mesh and a primitive. The model already owned the rings; a second rule in the engine would
  only have been a copy.
- One predicate, `engine::is_contour_operand`, is what the operand reader, the three cells and
  the armed mode's pick filter all read. The cells therefore enable on a body exactly as on the
  drawing, and the refusal still names the node by id.
- `RibbonContext::selected_ring` is a new flag rather than a widening of `selected_path`: the
  extrude cell must keep its own rule, because a body has no path payload to extrude twice and
  `object.path.extrude` refuses it by id.

## Ruled out

- Teaching `Project::object_path` to answer for a body: it is the editing door
  (`set_object_path`, the contour edit, the point drag) and a write through it would have to
  pick between two owners of the same chain.
- Making the result a constructive body: a boolean is 2D, and the solid boolean between two
  bodies is W1's feature list. A profile result stays a flat drawing — one ring, or a set.
- Reading the profile off the mesh or the derived contour cache: both are derived from the path
  the body owns, so the round trip through triangles would lose the exact segment ids the ring
  rules need.
