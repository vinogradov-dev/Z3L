# X53 — the line list's by-angle row draws a glyph and places the line

## What was measured

- `crates/ui/src/toolbars/spec.rs` declared `sketch.create.line.angle` as `icon: None, run: None`, so
  U67's list drew a blank row that ran nothing — the owner's report, and the whole of the entry.
- `DrawTool::Line`'s second stage already reads the pair: `stage()` gives it `Shape::Segment`
  (`crates/ui/src/draw_fields.rs`), the plates are `Length` and `Angle`, an angle is read with the
  half-turn rule of ADR 0134, and `PointState::placed` puts the point on the typed numbers whatever
  the pointer does (`a_typed_length_and_angle_place_the_point_exactly`). Enter then places the second
  point, `is_finished` is true, and the commit is one `object.path.create`.
- So the gesture the entry asks for — a start point, then a length and an angle — is exactly the
  gesture the *Line* cell's own method already has. Nothing about the geometry of a by-angle line was
  missing; only a row that draws and runs.
- `crates/ui/src/toolbars/spec.rs`'s `every_tool_kind_appears_exactly_once` test holds one `ToolKind` to exactly
  one id in the map, so a second row cannot simply run `ToolKind::Draw(DrawTool::Line)`.
- `method_id` is the map's inverse for a drawing tool, and its test walked `CONTOUR_TOOLS` only — the
  tools that carry a key. A method a cell's list starts and no key owns was unchecked.
- The family grammar for an angled figure already exists: `assets/icons/contour/construction-angle.svg`
  draws a corner, the angled line, the datum and the sweep in the reference ink. The new file is the
  same reading in the draw register, which is what tells the result from the construction.
- `assets/README.md` allows `path`, `rect`, `circle` and their paint attributes and nothing else, so a
  `stroke-dasharray` is not available: the dashed datum is three short paths, the way a drawing breaks
  a guide line.

## Decisions

- `DrawTool::LineByAngle` is its own kind with the line's own grammar: `points() == Some(2)`,
  `Shape::Segment` on the second stage, and `path_with` builds the same `Path::polyline`. The kind is
  separate because the map files one kind in one place; the measurement is shared because a line at an
  angle is a line, and a second pair of plates would be a second rule for the same number.
- `label()` stays the figure, `Message::ToolLine`: the path the tool commits is a line, so the node is
  named `Line 1` in the tree and a closure refusal reads `the Line tool cannot be closed`. The row's
  own words, `Message::ToolLineAngle` (*By angle* / *Под углом*), live in the map, where the list and
  the cell's hint draw them.
- The datum, the sweep and the control points of the icon: two points in the `view` ink are the two
  clicks, the line is the `draw` ink at 1.5, and the datum and its sweep are the `reference` ink at
  1.2 — the registers ADR 0124 separates. The datum is broken into three segments of 3.1 with 1.3
  gaps, which survives a 26 pt cell without an attribute the format forbids.
- The map's inverse is now checked from the map outward: every method of a cell whose `run` is
  `ToolKind::Draw(tool)` must answer that tool's `method_id`, and `CONTOUR_TOOLS` keeps the stronger
  claim that it carries a key.

## Ruled out

- Dropping the row: the entry, the icon and the owner's request all ask for it, and a method that
  names the typed pair is how a person learns the plates take numbers at all. The overlap is real and
  recorded here rather than hidden: the two rows differ in name and in nothing else.
- Reading the angle as a direction from `+X` for 0..360 in this method — what the icon's datum alone
  would suggest — because ADR 0134 settled the plate on the half-turn rule one commit before this
  entry was filed, and a second reading of the same arrow would make the number mean two things.
- Auto-committing the line when the second number is typed: Enter with both numbers locked already
  places the point and finishes the fixed tool (`show_fields` → `apply_click`), so a second path would
  be a second rule for one key.
- Widening `assets/README.md` for `stroke-dasharray`: one dash pattern for one icon does not earn an
  attribute the loader's allow-list does not carry, and the drawn breaks read better at 26 pt anyway.
