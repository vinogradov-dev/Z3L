# T7 — the rest of the icon set follows the v2 language, one tab at a time

T6 ships the pipeline, the seventh role, the six dimension artworks and the Sketch tab. This task
moves every remaining declared icon to the same language, one tab per commit, so the set never stays
half-redrawn for longer than a commit.

## The rules carried over from T6

Read `plan/notes/T6.md` first. In short: 24 grid, footprint 2.25..21.75, strokes 1.5 (geometry) /
1.2–1.3 (annotation, guides) / 1.6–1.8 (service and view), butt/miter, control circles r 2.0 with a
1.15 real gap, class ink for the result and `view` for the source/control, tones 0.12 (passive) and
0.45 (result), no digits, no masks, no background patches. The coverage band is 10–40 % of the 20 × 20
working area; the icon size is 26 pt in a 38 px ribbon cell and 22 pt in a toolbar.

## Procedure

1. Read the tab's icons and their current files; keep the meaning, redraw the geometry.
2. One tab per commit: redraw, update the README row if a name is added, run the icon gate, commit.
3. Keep the role inks; no eighth family. The only class moves are the reference set (dimension,
   construction, snap, ruler), which T6 starts and this task finishes where it applies.
4. Check the tab at 26 px and at 200 %; a row of icons must read as one set, not as a thin icon beside
   a thick one.
5. After the last tab, the icon count and the README table must agree; run `cargo xtask ci`.

## Done

Every declared icon is drawn in the v2 language; no v1 weight or 3..21 footprint remains; the icon
count and the README table agree; the live ribbon reads as one set at 100 % and 200 %; `cargo xtask
ci` is green; `plan/map.md` and the style guide point at the same rules.

## What the session measured and decided

- **Every tab but the cone is redrawn.** 71 files changed in six commits (Sketch remainder, Model,
  Furniture/Scene, View, Actions, Window). `primitives/cone` stays empty: `PrimitiveKind` has no
  cone, and the debt entry keeps the file with the primitive (`plan/debt.md`). No name, theme or
  family moved, so `crates/ui/src/icons.rs` and the README table stand unchanged.
- **Footprint and coverage** measured at 64 px on every file: all inside `2.25..21.75` and inside
  10–40 %. The tight arithmetics that cost a redraw: a flat plate's near corner is an acute miter
  spike (shelf `1.88..22.12` before the fix), a triangle's apex is one too (warning `1.5..22.5`), a
  solid gear is 44 % (fixed by stroking it, 35.6 %), and `maximize`/`restore` as two thin arrows were
  6 %, so each took the frame they act on.
- **One composition rule, now §9.3 of the style guide:** faces (fill only) first, then the
  silhouette, then the inner edges as separate `M` subpaths. Fills never land on a finished outline
  and no acute inner corner miters into a spike.
- **The pair family.** `offset` is two nested corners — the existing contour in `view`, the result
  in `draw` — because an open L cannot carry a tone. `trim` keeps the contour and fades the removed
  piece; `extend` carries it to the boundary with a solid arrow; `break` keeps an L and cuts one leg
  with two drafting slashes. The cutting edge, the cut marks and the existing geometry are the
  neutral `view` register, so the operation reads with no colour at all.
- **The three booleans are real union/subtract/intersect outlines**, not two overlapping circles: the
  arcs meet at `(12, 7.39)` and `(12, 16.61)` on two `r 5.5` circles at `(9, 12)` and `(15, 12)`, and
  the result carries the 0.45 tone. The first path drawn had the wrong sweep and showed the lens seam.
- **Scene vocabulary:** the product is the envelope wireframe (its hidden edges at 1.2), panel, post
  and shelf are one board at three proportions, the assembly keeps the solid connection dot.
- **Chrome:** the gear is a real cog polygon (8 teeth, `R 8.4`, `r 6.4`, hole 3.0) because a ring of
  spokes is `scene/light`; `minimize` is one solid bar (a bare 1.5 stroke would be 7 % coverage);
  `add`/`remove` share the two list rules and differ in the mark.
- **Looked at** each theme as a 64 px and a 128 px contact sheet, then at the real ribbon pitch
  (38 × 34 cell, 26 px glyph) in one row per tab, dark variant. The five display modes are told apart
  by tone and by which edges show; the six view directions are one frame and one arrow.
