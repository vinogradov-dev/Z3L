# X117 — What was measured

## What was measured

`panel.create` takes `nominal_size {length, width}` and a whole `placement {translation, rotation}`,
so the orientation of a board is the caller's to get right and nothing on the surface says which
corner of the finished part the translation names. The wardrobe of `app/tests/scenarios.rs` placed
every upright side with a quarter turn about +Y, which maps the panel's local +X onto world −Z, so
the zero corner sat at the top of the board (z = 2182) and the part grew downwards — the owner's
report. The rule the model states in three places (ADR 0082, ADR 0083, `crates/model/src/project/fill.rs`)
lived only in the fill tool: `Stance` already answers the rotation of the three shapes — `WidthAndDepth`
(shelf), `HeightAndDepth` (post) and `WidthAndHeight` (wall) — and `engine::guide().stances` prints
them, but no create command reads them.

## The owner's decisions (2026-11-23)

- The corner is the panel's own base corner, and it is always the one near the piece's origin: a
  build never rotates a panel so that its axis ends up above that corner.
- A panel's local frame is the same for every type: **X = length, Y = width, Z = thickness**, and
  the thickness comes from the material's record, not from the command.
- The type is the word the command takes. «Стенка» is one type — no overlay/inset split.
- A non-standard part keeps its own command later (by points, from a contour); the typed create is
  what a maker reaches for first.

## The design

`model::PanelType { Shelf, Post, Wall }` is the adapter between the maker's word and the two
authorities that already exist: its `class()` gives `10.11`, `10.10` and `10.12`, and its
`rotation()` gives the `Stance` rotation of the class's `fill` pair. One value type, no trait object:
the create command, the fill tool and a later points/contour command all reach the frame through it,
so the stance stops living in one caller.

`panel.create.standard` — `parent`, `name`, `material`, `type`, `at` (the base corner, world
millimetres), `length`, `width` (`Length`, local X and Y; the thickness is the material's). The
command builds `Placement::new(at, type.rotation())` and runs the same create body as `panel.create`
with `class = Some(type.class())`, so the local zero corner — face B, vertex 1 — lands at `at` and
every type leaves `min z = at.z`.

Axes per type, from the stance table: shelf — length +X, width +Y, thickness +Z; post — length +Z,
width +Y, thickness −X; wall — length +Z, width +X, thickness +Y.
