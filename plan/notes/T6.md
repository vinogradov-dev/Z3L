# T6 — the icon language v2 starts with the Sketch tab and six dimension types

The owner approved this language on 2026-11-15 from a rendered demo; the demo lived in `/tmp` and is
not part of the tree. Redraw from this note if it is gone. The approved data is below, not in the
style guide yet.

## The approved system

- **Grid**: 24; ink footprint **2.25..21.75** (not 2..22): the gate measures the raster's bounding
  box, and a circle at 2.2 reports 1.88 because its edge falls into the boundary pixel. A 0.25 inset
  keeps every curve inside.
- **Strokes**: result/silhouette `1.5`; annotation, inner edges, ticks `1.2–1.3`; butt caps and miter
  joins for geometry (round caps only where a shape is a dot).
- **Control nodes**: circles, radius **2.0**, separated from the contour by a **real path break** of
  **1.15**; never a mask, a clip or a background-coloured patch. The contour is shortened, not cut
  visually.
- **Colours**: one class hue per icon, plus tones of that hue (`fill-opacity` 0.12 passive, 0.45
  result). Two different hues only for the source/control (`view`) and the result (class), and for
  the dimension annotation (`reference`).
- **Size in the ribbon**: icon **26 pt**, cell **38 px**, toolbar **22 pt**. `RIBBON_ICON_POINT_SIZE`,
  `RIBBON_CELL_WIDTH` and `TOOL_ICON_POINT_SIZE` in `crates/ui/src/theme.rs` and `icons.rs`; check the
  strip tests (`the_row_is_counted_from_the_spec`, `every_ribbon_cell_is_the_same_cell`, the hint
  tests).
- **Gate**: footprint `2.25..21.75`; coverage **10–40 %** of the 20 × 20 working area (the v1 icons in
  the other tabs measure ~16–24 % on 20 × 20, so they stay inside until T7).
- **No digits, no unit, no text** in an icon. A dimension's value is the interface's.
- **Meaning**: the source, the base, the measured object and a control point are `view`; the result of
  the tool is its class ink; a dimension's annotation is `reference`. An icon that mixes a 2D source
  and a 3D result uses `view` for the source and the result's class for the body.

## The seven classes

| Class | Dark / light | Covers |
|---|---|---|
| draw | #58C8DC / #1C7C92 | 2D sketch geometry: line, polyline, rectangle, circle, arc, polygon; trim/extend/offset/fillet/chamfer on 2D |
| model | #6E9EF7 / #2E5CB8 | 3D solids: cuboid, cylinder, sphere, cone, extrude/revolve/sweep, booleans |
| scene | #55C7A4 / #237A5E | document objects: panel, post, shelf, product, assembly, hardware, camera, light |
| reference (new) | #E8D44D / #7A6A00 | ruler, dimensions, construction geometry, snaps/grid, work plane, guides |
| modify | #A98BF0 / #6B4BB0 | move, rotate, scale, mirror, copy/paste, undo/redo, rename, visibility |
| view | #B8C2CE / #5A6674 | orbit/pan/zoom, projection, layout, display, file, confirm/cancel, warning |
| danger | #E06A6A / #B33A3A | delete, remove, discard only |

The `reference` role is a seventh `Family` in `crates/ui/src/icons.rs`: add it to `master_hex`,
`RoleRamp` (`DARK` and `LIGHT`), `ink`, `Family::ALL` (length 7), and to the role table in
`assets/README.md`; update `assets/icons/STYLE_GUIDE.md` §1.1, §5.1 and §7. The role ramp stays
preset-independent (U70): the yellow is the same on P1, P2 and P4, and must clear 3:1 on panel,
ribbon and surface in both variants. Measured: 9.67:1 on the dark surfaces, 4.8:1 on paper; ΔE 29.3
(dark) / 25.8 (light) from the P1 copper accent, so it does not read as the accent.

Move these existing icons to `reference` when their tab is redrawn: `contour/dimension-*`,
`contour/construction-*`, `view/grid-snap`, `contour/measure`. The ruler is `contour/measure` and is
already the checked-in file from the interim fix; it is redrawn to the v2 metrics here.

## The six dimension types

The grammar is in `.pi/skills/drafting/references/dimensions.md` (T5). The approved geometry on the
24 grid; the object line is neutral `view` 1.3, the annotation `reference` 1.2–1.3, arrows solid
2.4 × 2.2, ticks 1.4, gap 1.1 at the tip:

| Type | Geometry |
|---|---|
| Overall | object y=18 x=4.5..19.5; witnesses x=4.5/19.5 y=9.5..18; dimension y=12 from 5.6 to 18.4; arrows both ends |
| From base | object y=18; base witness x=4.5 y=7.5..18; near witness x=15 y=11.5..18 (stops 2.5 above its own line); far witness x=19.5 y=7.5..18; **long dimension y=10**, **short y=14**; long 5.6..18.4, short 5.6..13.9; arrows both ends |
| Chain | object y=18; witnesses x=4.5/12/19.5 y=9.5..18; one dimension line y=12 from 5.6 to 18.4; arrows at the outer ends; the middle witness is the split (four arrows merge at 26 px) |
| Angular | rays (5,19)–(20,19) and (5,19)–(5,4) neutral; arc r=10 from (15,19) to (5,9) yellow; 45° ticks at the ends (arrowheads lose their shape below ~40 px) |
| Radius | neutral circle r=8.6; centre node r=2; leader at 45° from (14.23,9.77) to (15.61,8.39); arrow tip (17.3,6.7), base (15.61,8.39) ± (0.778,0.778); not horizontal |
| Diameter | neutral circle r=8.6; line at 45° (8.39,15.61)–(15.61,8.39); arrows at (17.3,6.7) and (6.7,17.3); no centre node |

The drawing rules behind them: each size once; the smallest nearest the object and the largest
outermost; a near point's extension stops at its own dimension line; radius leaders are angled; a
diameter passes through the centre. The drawing arrow touches the extension line; the icon keeps
1.0–1.1 of air on purpose.

New artwork: `dimension-baseline` and `dimension-chain` under `contour` (methods of the linear
dimension), and `dimension-diameter` (the `radius` cell's variant). They are planned methods today,
so the ribbon map wires them when the dimension commands land; the icon files and the README row land
here. The icon count in `every_icon_uri_names_its_theme_and_file` and the README theme row must grow
from 104 to 107.

## The Sketch batch

Redraw the `contour` create tools and the ruler in v2: `line`, `polyline`, `rectangle`,
`rectangle-centre`, `rectangle-centre-directed`, `circle`, `circle-three-points`, `arc`,
`arc-centre`, `polygon`, `measure`, the dimension set, and the draft `close`/`cancel`. The demo
checked the four create shapes: line (cyan line, neutral end nodes), rectangle (cyan outline with two
neutral corner nodes), circle (cyan circle, neutral centre node and neutral radius line), and move
(violet arrows, neutral centre node). The upper-left corner of the rectangle is broken by 1.15 around
the node; the line ends are shortened along the direction by the node radius plus the gap.
