# T6 — the icon language v2 starts with the Sketch tab and six dimension types

The owner approved this language on 2026-11-15 from a rendered demo; the demo lived in `/tmp` and is
not part of the tree. It was still there when the task was taken: `/tmp/icons-demo` (line, rectangle,
circle, ruler), `/tmp/icons-v2` (the ruler and the cuboid in the new metrics) and `/tmp/icons-dim`
(the six dimension drawings and their 26 px renders). They were taken verbatim where they exist; the
rest was redrawn from the rules below.

The language is now written down, so this note no longer carries it: ADR
[0124](../../docs/decisions/0124-the-icon-language-is-v2.md) decides it, `assets/icons/STYLE_GUIDE.md`
§5.1, §7.1–§7.6 state it as a drawing rule, `assets/README.md` holds the role table and the format, and
`.pi/skills/drafting/references/dimensions.md` holds the dimension grammar.

## What T6 measured and decided

- `Family::Reference` is the seventh entry, `Family::ALL` is 7 long, and `RoleRamp` gained the
  `reference` field: `#E8D44D` dark, `#7A6A00` light. Tags moved to it: `contour/measure`,
  `contour/construction-*` (4), `contour/dimension-*` (6) and `view/grid-snap`. `contour/cancel`
  moved to `view`: it discards a draft, it draws nothing.
- Gate: footprint `2.25..21.75`, coverage 10–40 % of the 20 × 20 area (400 units²). The v1 icons
  measure 16.2–36.4 % on that denominator — 20–45 % of 18² is the same ink — so every unredrawn tab
  still passes and T7 can go one tab at a time.
- Count: 104 → 107 files (`dimension-baseline`, `dimension-chain`, `dimension-diameter`).
- Sizes: `RIBBON_ICON_POINT_SIZE` 26, `RIBBON_CELL_WIDTH` 38, `RIBBON_ROW_HEIGHT` 34,
  `TOOL_ICON_POINT_SIZE` 22. The open ribbon is 80 pt and the split cell 48. The row grew because
  26 pt in 30 leaves two points above and below where the v1 air was four.
- The three new icons are files only: their tools are planned, so the ribbon map still draws a label
  and T7 or the dimension commands wire the glyph.

## The six dimension types, as drawn

Object line neutral `view` 1.3, annotation `reference` 1.2–1.3, arrows solid 2.4 × 2.2, gap 1.1 at the
tip. Numbering is the reading order of `.pi/skills/drafting/references/dimensions.md`.

| File | Geometry |
|---|---|
| `dimension-linear` (overall) | object y=18 x=4.5..19.5; witnesses x=4.5/19.5 y=9.5..18; dimension y=12 from 5.6 to 18.4; arrows both ends |
| `dimension-baseline` (from base) | object y=18; base witness x=4.5 y=7.5..18; near witness x=15 y=11.5..18; far witness x=19.5 y=7.5..18; long dimension y=10, short y=14; long 5.6..18.4, short 5.6..13.9; arrows both ends |
| `dimension-chain` | object y=18; witnesses x=4.5/12/19.5 y=9.5..18; one dimension line y=12 from 5.6 to 18.4; arrows at the outer ends, the middle witness is the split — four arrows merge at 26 px |
| `dimension-angular` | rays (5,19)–(20,19) and (5,19)–(5,4) neutral; arc r=10 from (15,19) to (5,9) yellow; 45° ticks at the ends, because an arrowhead loses its shape below ~40 px |
| `dimension-radius` | neutral circle r=8.6; centre node r=2; leader at 45° from (14.23,9.77) to (15.61,8.39); arrow tip (17.3,6.7), base (15.61,8.39) ± (0.778,0.778); never horizontal |
| `dimension-diameter` | neutral circle r=8.6; line at 45° (8.39,15.61)–(15.61,8.39); arrows at (17.3,6.7) and (6.7,17.3); no centre node |

The drawing rules behind them: each size once; the smallest nearest the object and the largest
outermost; a near point's extension stops at its own dimension line; a radius leader is angled; a
diameter passes through the centre. A drawing's arrow touches the extension line; the icon keeps 1.0
of air on purpose.

## The redrawn Sketch artwork, on the 24 grid

Node circle `r 2` in `view`; contour `1.5` in the class ink; annotation `1.3` in `view`; every break
3.15 from a node centre; `stroke-linecap="butt"`, `stroke-linejoin="miter"` on the root. The
checked-in SVG is the source of truth; these coordinates are the recipe, so a later session can
redraw a file without the demo.

| File | Recipe |
|---|---|
| `polyline` | nodes (4.25,19.75) (9.5,4.25) (14.5,19.75) (19.75,4.25); three segments, each shortened 3.15 at both ends |
| `arc` | three points on `c (12,12.85) r 8.6` at 128.3°/270°/411.7°; two runs, broken 3.15 at both ends and around the middle node — the through-point is the top |
| `arc-centre` | centre (6.25,17.75) `r 13.5`; quarter arc 270°→360°, two radii at 270° and 0°, each shortened 3.15 at both ends; three nodes |
| `circle-three-points` | `c (12,12) r 7.4`, nodes at 270°/30°/150°, the circle cut 3.15 either side of each |
| `polygon` | hexagon `r 7.4` centred, one centre node and a radius annotation stopping 1.15 short of the right vertex — a node on that vertex leaves a 1.1-unit leader, which is a dot, not a line |
| `rectangle-centre` | rectangle `(4.25,4.25)–(19.75,19.75)`, the far corner open 3.15 on both edges; centre node and a leader to the corner node |
| `rectangle-centre-directed` | the same rectangle `6.2 × 4.8` turned −18° about (12,12); the `+u` corner open, centre node, leader to that corner |
| `close` | source `(5.5,19) → (5.5,8) → (19,8)` in `view 1.2`, the closing edge `(19,8) → (5.5,19)` in `draw 1.5`; three nodes |
| `cancel` | one X in `view 1.5`, corners (4.75,4.75)–(19.25,19.25) |
| `construction-*` | the guide register: `1.5` bars or rays, `1.2` dashed runs and ticks, a `view` node; a dash is a short path, because `stroke-dasharray` is outside the README's closed paint list |
| `grid-snap` | four grid lines `reference 1.2`, one `view` node at their crossing |

Measured coverage (64 px raster, alpha above 16): line 11.3, polyline 23.8, rectangle 24.8,
rectangle-centre 28.7, rectangle-centre-directed 20.9, circle 24.8, circle-three-points 19.6, arc
20.6, arc-centre 19.6, polygon 18.4, measure 21.0, close 17.1, cancel 14.8; dimension-linear 13.7,
-baseline 19.0, -chain 15.6, -angular 15.0, -radius 21.9, -diameter 22.1. Every bbox is inside
`2.25..21.75`.

Arithmetic was done with a throwaway helper in `/tmp`; no generator enters the tree
(`STYLE_GUIDE.md` §15).

## Looked at

The offscreen matrix (`cargo test -p furnicraft --bin furnicraft -- --ignored`) rendered 72 cells; the
*Sketch* row was read at 100 % and 200 % in the dark and the light variant. The glyphs are crisp at
200 %, the cells are one pitch, and the two *Draft* cells show the disabled tone because nothing is
drafted in an empty scene — that is `ready`, not the drawing. A 64 px contact sheet of all 32 contour
icons answered the two questions the gate cannot: a node's 1.15 gap reads, and a dimension arrowhead
keeps its air.
