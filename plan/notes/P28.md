# P28 — What was measured

## What was measured

- `step` read the note with `read(root, &note_path)?` and nothing else, so a missing file was the
  whole failure: `cannot read `plan/SESSION.agent.md`: No such file or directory` (J15, measured
  2026-11-23 in the `stream/agent` worktree).
- The note is a working-tree file: `task start` writes it in the checkout that runs the verb, and a
  stream sees only what its branch carries. `own_task_refusal` already lets a stream run `step` for
  its own task, so only the read was in the way.
- The backlog entry a stream *does* see carries everything the note's four required fields need:
  the id, the lead as `goal`, the `[~]` marker as the proof that the task runs.

## Decisions

- **`step` writes the note from the entry when the file is absent.** Shape (b) of the entry: one
  writer, no extra commit in the primary, and the verb AGENTS.md §6.2 promises works in the stream.
  The fresh note is `session_note` — the same function `start` uses — so the fields and their
  defaults cannot drift between the two verbs.
- **Only while the task is in progress.** A missing note on a `[ ]` task is correct and stays a
  refusal, now naming `cargo xtask task start <ID>` instead of a bare read error: the gate refuses a
  note for a task nobody runs, so writing one would only move the failure.
- **`--now`, `--run`, `--resume` and `--add` land on the new note** because they are applied after
  it is built; `--tick` ticks the starting step, which is what a session that lost its note first
  asks for.

## Ruled out

- **Shape (a), the primary committing the start note.** It needs no tool change but makes a stream's
  first verb depend on a commit it cannot make, and the Done clause names the absent-note case as the
  one to cover.
- **Widening `own_task_refusal` or letting `step` write `plan/BACKLOG.md`.** The marker and the order
  stay the primary's; the note is the stream's, and this keeps it that way.
- **A silent empty note when the task cannot be found.** `find` names the id, which is the sentence a
  session with a stale branch needs.
