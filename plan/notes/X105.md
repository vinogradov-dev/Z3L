# X105 — the parallelepiped is a ribbon gesture, and no command names it

the parallelepiped is a ribbon gesture, and no command names it

## What was measured

- `crates/ui/src/toolbars/spec.rs:748` — the cell `model.primitives.cuboid` (label `Message::ToolBox`,
  "Box") runs `ToolKind::Body(DrawTool::Rectangle)` and lists the sketch's three other rectangle
  methods as variants. It arms a gesture, so no command id is behind the word a caller reads.
- `crates/engine/src/object_cmds.rs` — `object.primitive.create` takes a `PrimitiveShape`, which is
  `Sphere | Cone` only (`crates/model/src/primitive.rs:327`); a caller that asks for a box finds
  nothing, and the two ids that could make one carry no size: `object.path.create` takes a drawn
  `Path`, `object.extrude.create` a drawn `Contour` plus a height.
- `crates/model/src/primitive.rs:3` and ADR 0138 — a box is *not* a primitive: it is a drawn profile
  swept on Z, stored as `Geometry::Constructive`, and `Primitive::Cuboid` was deleted with schema 25.
- `crates/mcp/src/server.rs:262` — `command_list` prints `spec.label()` for every registered command,
  so the word a model reads is the command's own `Message` and nothing else.

## Decisions

- The shape gets a command, not a primitive variant: `object.cuboid.create`, taking `parent`, `name`,
  `width`, `depth`, `height` and `placement`. The alternative in the entry — a `Cuboid` arm of
  `PrimitiveShape` — would resurrect the parameter set ADR 0138 retired and give the tree two ways to
  store one box; the constructive body is the one the gesture, the card and the boolean steps already
  handle.
- The command's label is `Message::ToolBox`, the cell's own message: `command_list` then names the
  shape exactly as the ribbon does, and one word belongs to one id (`place-capability` §6).
- The body is a `Path::rectangle` from the local zero, rebased by `rebase_origin_at` with
  `FrameAnchor::CreationOrigin`, then `Constructive::extrude`. So the local zero is the centre of the
  base face — ADR 0082's closed-ring anchor, which ADR 0138 already gives a drawn box — and the
  command reuses the anchoring rule instead of restating it.
- A side is refused unless it is positive and inside `model::MAX_CONTOUR_COORDINATE` (1000 m, the same
  ceiling `Extrude` and every contour coordinate obey). No new minimum: the gesture accepts a
  micrometre-wide rectangle, and a command that refused what the hand can draw would be a second rule.
- The inventory row is `Place::Api` with the reason in `plan/debt.md`: the cell must stay the drawing
  gesture (ADR 0138 keeps the four rectangle methods on it), so the command's only doors today are the
  command line and the assistant — which is exactly the caller the entry's Why failed.

## Ruled out

- A `Cuboid` variant of `PrimitiveShape` accepted by `object.primitive.create`: it would need
  `PrimitiveKind::Cuboid`, a mesh builder beside the contour sweep, arms in `contact_shape`, `snap`,
  `object_card` and `extrude_gizmo`, and an ADR reversing 0138 — for a body the tree already stores.
- Moving the cell onto the command: the box cell is the sketch's rectangle grammar (ADR 0138), so a
  cell that dispatched a command would lose the three other rectangle methods and the height pull.
- A second ribbon row named `object.cuboid.create`: the ribbon is curated and the cell already holds
  the word; two cells for one shape is the duplication the entry's Shape asks to avoid.
